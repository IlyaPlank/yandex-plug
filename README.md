# 🎵 Yandex plug

Расширение для Google Chrome, которое добавляет дополнительные возможности управления [Яндекс Музыкой](https://music.yandex.ru/).

## ✨ Возможности

- Расширенное управление с клавиатуры.
- Пауза / продолжение воспроизведения по `Space`.
- Копирование названия трека и исполнителя по `Ctrl + C`.
- Дополнительные настройки отображения интерфейса.
- Настройки сохраняются между перезапусками браузера.

---

## 📦 Установка

Поскольку расширение не опубликовано в Chrome Web Store, его необходимо установить вручную.

### 1. Скачайте расширение

Скачайте репозиторий на компьютер:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Или нажмите:

**Code → Download ZIP**

После скачивания распакуйте архив в удобное место.

> ⚠️ Не удаляйте папку с расширением после установки. Chrome загружает расширение непосредственно из этой папки.

---

### 2. Откройте страницу расширений Chrome

В адресной строке браузера откройте:

```text
chrome://extensions/
```

Также можно открыть её через меню:

**⋮ → Расширения → Управление расширениями**

---

### 3. Включите режим разработчика

В правом верхнем углу страницы включите переключатель:

**Режим разработчика (Developer mode)**

После этого появятся дополнительные кнопки.

---

### 4. Загрузите расширение

Нажмите:

**Загрузить распакованное расширение**

или

**Load unpacked**

---

### 5. Выберите папку расширения

Выберите папку, в которой находится файл:

```text
manifest.json
```

Например:

```text
yandex-plug/
├── manifest.json
├── content.js
├── popup.html
├── popup.js
├── styles.css
└── ...
```

Нажмите **Выбрать папку**.

После этого расширение появится в списке установленных расширений Chrome.

---

## 🚀 Использование

Откройте [Яндекс Музыку](https://music.yandex.ru/) и обновите страницу после установки расширения.

### Управление воспроизведением

Нажмите:

```text
Space
```

чтобы поставить музыку на паузу или продолжить воспроизведение.

> Если курсор находится в поле ввода текста, нажатие `Space` не управляет воспроизведением.

### Копирование информации о треке

Нажмите:

```text
Ctrl + C
```

чтобы скопировать название текущего трека и исполнителя.

Комбинация работает только в том случае, если на странице не выделен текст.

## ⚙️ Настройки

Открыть настройки расширения можно через его иконку в панели расширений Chrome.

После изменения настроек они сохраняются автоматически.

---

## 🔄 Обновление расширения

Если вы скачали новую версию расширения:

1. Обновите файлы расширения.
2. Откройте:

```text
chrome://extensions/
```

3. Найдите расширение.
4. Нажмите кнопку **↻ Обновить**.

После этого обновите страницу Яндекс Музыки.

---

## 🗑️ Удаление

Чтобы удалить расширение:

1. Откройте:

```text
chrome://extensions/
```

2. Найдите **Yandex Music Controls**.
3. Нажмите **Удалить**.
4. Подтвердите удаление.

---

## 🛠️ Разработка

Если вы хотите изменить код расширения, клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

Затем загрузите папку через:

```text
chrome://extensions/
```

→ **Режим разработчика**

→ **Загрузить распакованное расширение**

После внесения изменений нажмите **↻ Обновить** на странице расширений.
